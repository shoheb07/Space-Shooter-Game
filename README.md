# Space-Shooter-Game
Space Shooter is a 2D arcade game where the player controls a spaceship, shoots incoming enemies, and earns points by destroying them. The game ends when an enemy collides with the player.

Space Shooter Game

Overview

Space Shooter is a 2D arcade game developed using Python and Pygame. Players control a spaceship, destroy incoming enemies, and try to achieve the highest possible score while avoiding collisions.

Features

* Spaceship movement
* Enemy generation
* Shooting mechanics
* Collision detection
* Score tracking
* Real-time gameplay

Technologies Used

* Python
* Pygame

Installation

Install dependencies:

pip install pygame


Run Project

python space_shooter.py

Controls

* Left Arrow → Move Left
* Right Arrow → Move Right
* Spacebar → Shoot


Learning Outcomes

* Collision detection
* Object-oriented game logic
* Real-time rendering
